# XBoard 支付宝电脑网站支付插件

适用于 XBoard 的支付宝电脑网站支付插件，调用 `alipay.trade.page.pay`，支持 RSA2 请求签名、自动提交支付表单、异步通知验签和订单金额校验。

## 安装

将本目录打包成 ZIP 文件，在 XBoard 插件管理页面上传、安装并启用。插件代码为 `alipay_pagepay`，安装后的目录应为 `plugins/AlipayPagepay`。

## 配置

- 支付宝应用 APPID
- PHP 使用的 PKCS#1 应用私钥
- 支付宝公钥（不是应用公钥）
- 支付宝商户 PID
- 正式环境或沙箱环境
- 可选商品名称和支付有效期

XBoard 后台显示的异步通知地址必须能通过公网 HTTPS 访问，且不能发生重定向。同步返回只负责将用户带回订单页面，订单是否支付成功必须以验签后的异步通知或服务端查单结果为准。

## 安全说明

私钥只能保存在服务端支付配置中，禁止写入日志、客户端或公共代码仓库。正式上线前，请使用真实商户配置完成完整支付流程、异步通知和订单金额校验测试。
